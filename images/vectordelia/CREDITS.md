# Vectordelia asset credits

These vector-style images come from the **Frutiger Aero Archive** resource page:

- https://frutigeraeroarchive.org/resources/metro

Downloaded on 2026-11-09, then resized and converted to WebP with transparency for this
personal, non-commercial portfolio. The archive describes the collection as images for
making Frutiger Aero-themed collages, images and edits.

| Local file | Archive file | Use |
| --- | --- | --- |
| `scene-city.webp` | `metro_44.png` (derived) | Background scene without the arrows |
| `arrow-main.webp` | `metro_44.png` (derived) | Large left arrow + small left arrow |
| `arrow-sign.webp` | `metro_44.png` (derived) | Arrow inside the yellow sign |
| `arrow-right.webp` | `metro_44.png` (derived) | Yellow arrow on the right |
| `stars-halftone.webp` | `metro_62.png` | Footer decoration |
| `flourish.webp` | `metro_60.png` | About panel accent |

`scene-city.webp` is the original image with the arrow regions removed and the white
background keyed out. The arrow layers are extracted from the same image with transparent
backgrounds, so the scene and arrows can animate independently.

The site is a personal, non-commercial project. Replace these assets or confirm the
archive's terms before any commercial use.
